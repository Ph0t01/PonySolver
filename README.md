# 找小马求解器 · Android 本地自动化助手

一个面向“找小马 / Queens / Star Battle”类 `n×n` 约束谜题的 Android 本地求解工具。

它不需要开发者模式，不需要 ADB，不需要连接电脑。核心思路是把游戏截图转成颜色区域矩阵，再用 CSP 约束求解器计算答案，并提供两种完成方式：

- **安全模式**：悬浮显示答案点，用户照着红点手动双击；
- **进阶模式**：用户确认后，延迟 5 秒自动双击答案点。

> 进阶模式需要用户主动开启无障碍自动点击服务。默认推荐先使用安全模式。

## 功能亮点

- **本地离线运行**：不依赖服务器，不上传截图；
- **截图导入**：支持从相册选择截图，也支持系统分享图片到本应用；
- **棋盘框选**：自动给出初始棋盘范围，并支持拖动红框精调；
- **颜色聚类**：基于 CIE Lab 颜色特征识别不同颜色区域；
- **多候选校验**：多采样尺度、多初始化投票，只接受稳定唯一解；
- **CSP 求解**：同时满足每行一匹、每列一匹、每色一匹、八邻域不相邻；
- **悬浮答案点**：在游戏界面上方显示半透明红点，便于快速手动双击；
- **可选自动双击**：开启无障碍服务后，可在 5 秒倒计时后自动双击答案格；
- **坐标复制**：一键复制按列排序的答案坐标，便于人工核对。

## 当前权限设计

Manifest 中声明：

- `SYSTEM_ALERT_WINDOW`：用于显示半透明悬浮答案点；
- `BIND_ACCESSIBILITY_SERVICE`：用于可选的“用户确认后自动双击”。

没有声明：

- `INTERNET`
- `READ_CONTACTS`
- `RECORD_AUDIO`
- `CAMERA`
- `ACCESS_FINE_LOCATION`
- `READ_SMS`
- `CALL_PHONE`

也就是说，应用不会联网，不读取通讯录、短信、位置、相机、麦克风等敏感信息。

## 使用方法

### 方式一：安全模式，悬浮提示，手动双击

1. 在游戏界面截图。
2. 打开“找小马求解器”。
3. 点击“导入截图”，选择刚才的截图；也可以从相册/系统分享菜单直接分享图片到本应用。
4. 输入棋盘大小 `n`，例如 `10`。
5. 拖动红框四角，只框选彩色棋盘，不要包含左侧/底部坐标数字。
6. 点击“求解”。
7. 如果预览红点正确，点击“显示悬浮答案”。
8. 回到游戏界面，按红点手动双击。
9. 用完点击“隐藏悬浮”，或等待自动隐藏。

### 方式二：进阶模式，延迟自动双击

1. 先按“方式一”完成导入截图、框选棋盘、求解。
2. 点击“开启点击权限”。
3. 在系统无障碍设置中找到“找小马求解器”，开启服务。
4. 返回本应用。
5. 点击“5秒后自动双击”。
6. 立刻切回游戏界面。
7. 应用会在倒计时结束后，按求解出的答案点执行自动双击。

建议先用安全模式验证若干关，确认红框与红点稳定后，再使用自动双击。

## 求解原理

对 `n×n` 棋盘定义二值变量：

```text
x[i][j] = 1 表示第 i 行第 j 列放一匹小马
```

约束为：

```text
每行恰好 1 匹
每列恰好 1 匹
每种颜色区域恰好 1 匹
任意两匹不能在八邻域相邻
```

程序先从截图中提取每个格子的中心颜色，用多组采样参数生成候选颜色矩阵，再将候选矩阵送入 CSP 回溯求解器。只有稳定得到唯一解时，才输出结果。

## 构建 APK

### GitHub Actions 构建

仓库根目录应包含：

```text
app/
build.gradle
settings.gradle
.github/workflows/build-apk.yml
```

上传或更新代码后：

1. 打开 GitHub 仓库的 `Actions` 页面；
2. 选择 `Build Android APK`；
3. 点击 `Run workflow`；
4. 等待构建完成；
5. 在构建记录底部下载 `PonySolver-debug-apk`；
6. 解压后得到 `app-debug.apk`。

### Android Studio 构建

1. File → Open → 选择 `PonySolver` 文件夹；
2. 等待 Gradle Sync；
3. Build → Build Bundle(s) / APK(s) → Build APK(s)；
4. 生成的调试 APK 一般在：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 常见问题

### 求解失败

通常是以下原因：

- `n` 填错；
- 红框包含了坐标数字、按钮或边框外背景；
- 截图被压缩、模糊或棋盘被遮挡；
- 同色区域亮度变化过大；
- 该关截图不是完整棋盘状态。

处理方式：微调红框边界，只框住彩色格子区域，然后重新求解。

### 自动双击错位

自动双击依赖“截图像素坐标”和“当前游戏界面坐标”一致。请确认：

- 截图来自当前同一界面；
- 自动双击前已切回同一游戏界面；
- 没有旋转屏幕；
- 没有开启分屏、小窗、缩放显示等导致坐标变化的模式。

如果不确定，先使用“显示悬浮答案”模式，手动确认红点位置。
