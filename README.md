# 找小马求解器（vivo / 抖音小程序安全版）

这是一个本地 Android 工程，目标是解决“找小马”类 n×n 约束谜题。

当前版本做的是安全版：

- 导入抖音小程序截图；
- 手动/自动框选彩色棋盘区域；
- 输入棋盘大小 n；
- 自动识别颜色区域；
- 使用 CSP 求解；
- 在截图上显示答案点；
- 可选开启悬浮答案点，回到抖音后照着红点手动双击。

当前版本不包含无障碍自动点击，因此不需要开启开发者模式、ADB 或无障碍权限。悬浮答案功能需要 Android 悬浮窗权限。

## 权限

Manifest 中只声明：

- `SYSTEM_ALERT_WINDOW`：用于在抖音界面上方显示半透明答案点。

没有声明：

- INTERNET
- READ_CONTACTS
- RECORD_AUDIO
- CAMERA
- ACCESS_FINE_LOCATION
- READ_SMS
- CALL_PHONE

## 使用方法

1. 在抖音小程序游戏界面截图。
2. 打开“找小马求解器”。
3. 点击“导入截图”，选择刚才的截图；也可以从相册/系统分享菜单直接分享图片到本应用。
4. 输入棋盘大小 n，例如 10。
5. 拖动红框四角，只框选彩色棋盘，不要包含左侧/底部坐标数字。
6. 点击“求解”。
7. 如果红点正确，点击“显示悬浮答案”。
8. 回到抖音小程序，按红点手动双击。
9. 用完点击“隐藏悬浮”，或等待 90 秒自动隐藏。

## 构建 APK

用 Android Studio 打开本目录：

1. File → Open → 选择 `PonySolver` 文件夹；
2. 等待 Gradle Sync；
3. Build → Build Bundle(s) / APK(s) → Build APK(s)；
4. 生成的调试 APK 一般在：
   `app/build/outputs/apk/debug/app-debug.apk`

## 备注

截图识别的稳定性取决于棋盘框选区域。如果求解失败，通常是：

- n 填错；
- 红框包含了坐标数字、按钮或边框外背景；
- 截图压缩、模糊或棋盘被遮挡；
- 同色区域亮度变化过大。

遇到失败时，微调红框边界后重新求解。
